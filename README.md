##  Descripción
Este proyecto consiste en el diseño e implementación de una base de datos relacional para un gimnasio usando **PostgreSQL**. 
Permite gestionar información de clientes, entrenadores, rutinas, nutricionistas, membresías, pagos y evaluaciones nutricionales, garantizando seguridad y consistencia de los datos.

---

##  Estructura de la Base de Datos

| Tabla                  | Descripción |
|------------------------|-------------|
| `cliente`              | Información personal de los clientes |
| `entrenador`           | Datos de los entrenadores |
| `membresia`            | Tipos de membresía, duración y costo |
| `rutina`               | Rutinas de entrenamiento de los clientes |
| `ejercicio`            | Ejercicios asociados a cada rutina |
| `nutricionista`        | Información de nutricionistas y planes |
| `evaluacion_nutricional` | Evaluaciones nutricionales de clientes |
| `pago`                 | Registro de pagos de membresías |
| `facturacion`          | Facturas emitidas a los clientes |
